## Overview

This guide walks through connecting your first set of sensors to the
renewvan monitoring hub.

## Requirements

Before you start, make sure you have the monitoring hub and at least one
sensor module.

## Wiring the sensors

Connect each sensor to the hub over its labeled input. The hub auto-detects
sensor type on first boot.

## Verifying readings

Open the dashboard and confirm each sensor reports a live value within a few
seconds of being wired in.
